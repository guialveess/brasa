## 0.11.0

- **New app icon.** Nested rounded squares in Brasa's own ember gradient, replacing the icon
  inherited from the original fork.
- **Tabs reorder live.** Dragging a tab over another swaps them in place and slides into position,
  instead of just marking where it would land.
- **Updates actually work now.** The release build was missing the flag that turns on the in-app
  updater, so checking for updates silently did nothing. Fixed.
- **Simpler environment editor.** The `.env`/`.local.env` split only shows up once you actually use
  it; a variable's "stored in" chip now reads "Shared" or "Local only" instead of a raw file name.
- **Recent workspaces, as cards.** The welcome tab shows your recent workspaces with their request
  count and when they last changed.
- Moving several requests or folders at once is faster in a large workspace.
- The sidebar and the Git panel no longer overlap their own content when resized narrow.
