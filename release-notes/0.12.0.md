## 0.12.0

- **Windows gets a real installer.** Brasa now ships an Inno Setup installer alongside the
  portable zip, and `install.ps1` uses it by default. This is what makes the in-app updater work
  on Windows: a copy installed this way can now check for updates and install them silently,
  the same as macOS already could. The portable zip is still there for anyone who wants it, but a
  portable copy only gets notified of a new version, not updated in place.
